Entidades HTML são códigos especiais usados para exibir caracteres reservados do sistema ou símbolos que não existem no teclado comum.

  • "&lt;", que vira o caractere <, utilizado para não conflitar com o uso do mesmo para abrir tags
  • "&gt;", que vira o caractere >, utilizado para não conflitar com o uso do mesmo para fechar tags
  • "&amp;", que vira o caractere especial &, e pode ser utilizado para escrever as entidades na página sem chamá-las, exatamente como foi feito para cada linha dessa lista
  • "&quot;", que vira o caractere especial "
